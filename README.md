This is a simple ATM Banking System developed using Java.
The project simulates basic ATM operations like withdrawal, deposit, and balance inquiry using console-based interaction.

It is a beginner-friendly project that demonstrates core Object-Oriented Programming (OOP) concepts.

🚀 Features
💰 Withdraw Money
💵 Deposit Money
📊 Check Account Balance
❌ Exit System
🔁 Continuous loop for multiple transactions
🛠️ Technologies Used
Java
OOP Concepts (Inheritance, Classes, Objects)
Scanner Class (User Input)
🧠 Concepts Covered
Class & Object
Inheritance (ATMTransaction extends ATM)
Constructor
Method Implementation
Conditional Statements (if-else)
Loop (while(true))
Switch Case
